# Project Two Copy Density Design

**Date:** 2026-04-03

## Goal

Reduce the copy density of the second project card so its footer CTA has breathing room comparable to the other project cards.

## Root Cause

- The second project card carries the longest title-supporting description and the densest delivery bullets.
- The card layout is shared, so the most copy-heavy project becomes the one that visually compresses the footer first.
- The CTA styling is no longer the main blocker; copy length is.

## Approved Design

- Keep the existing card layout and CTA treatment.
- Shorten only the second project card's description, delivery bullets, and desktop delivery bullets.
- Preserve the meaning of the project: six services, saga orchestration, and guarded releases.
- Do not change project stats, title, status, or other cards' copy.

## Expected Result

- Project two reads more like the other cards in length and rhythm.
- The footer CTA sits with more breathing room without requiring another layout redesign.
